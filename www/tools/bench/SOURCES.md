# Sources and constants


## Value converter and frequency

Engineering prefixes (SI): giga 10⁹ down to pico 10⁻¹². Wavelength = c × velocity factor ÷ f, with c = 299,792,458 m/s.

## Number bases

Standard positional notation; signed values use two's complement for 8, 16, and 32 bits.

## E-series

IEC 60063 preferred numbers: E6, E12, E24, E48, and E96. E48 is every other E96 value.

## Resistor color code, capacitor codes

IEC 60062 color code and marking codes. Temperature coefficient colors: brown 100, red 50, orange 15, yellow 25, blue 10, violet 5 ppm/°C (black 250 on some parts).

## I²C addresses

The usual 7-bit addresses for common breakout boards, collected from the chip datasheets and the common board documentation. Jumpers and variants change them. To be confirmed with a scanner and your board.

## AWG

Diameter = 0.127 mm × 92^((36 − n) ÷ 39) (ASTM B258). Copper resistivity 1.724 × 10⁻⁸ Ω·m at 20 °C.

## Logic levels

Typical datasheet values, as listed in the Embedded Systems Toolkit sources.
